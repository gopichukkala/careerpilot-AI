# 🚀 CareerPilot AI

> Your AI-Powered Academic & Career Companion

CareerPilot AI is a full-stack AI-powered web platform designed to help students throughout their academic journey and placement preparation.

## ✨ Features

- 📚 Smart Learning
- 💼 Career Development
- 🗂️ Portfolio Hub
- 🔍 Opportunity Hub
- 📊 Dashboard & Analytics

## 🏗️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Framer Motion

### Backend
- Flask
- SQLAlchemy
- JWT Authentication

### Database
- MySQL

### AI
- OCR
- RAG
- Resume Analysis
- Quiz Generation
- AI Recommendations
